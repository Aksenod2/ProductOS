## 7. Версия для показа

- **Версия карты / дата:**
- **Канонический снимок:** этот `PRODUCT-MAP.md`; commit hash передаётся рядом
  с картой после машинной проверки и не записывается внутрь собственного снимка.
- **Рабочая Google Sheet:** не обязательна; допустима только когда все ссылки
  `Подробности` открываются у владельца.
- **Что будет с картой дальше:** решает владелец вне этого процесса.
