# TRACEABILITY — служебная трассировка Product Map

Этот файл нужен команде, а не владельцу. Служебные ID не переносятся на основную
карту и не заменяют человеческие названия.

## Правила ID

- `SRC-001` — источник;
- `NODE-001` — проектировочный узел;
- `DEC-001` — существенная развилка;
- ID копируется без перенумерации и изменения регистра во всех файлах.

## Реестр известных узлов

| Node ID | Человеческое название | Как обнаружен / Source ID | Статус | Файл | Точная координата на карте |
|---|---|---|---|---|---|
| NODE-001 |  | SRC-001 | предполагается / проектируется / принято / не покрыто | `nodes/...md` | `PRODUCT-MAP.md` → раздел + строка; для Sheet: вкладка + диапазон |

## Сквозная связь

| Source ID | Node ID + название | Decision IDs | Точная координата в Product Map | Подробный файл |
|---|---|---|---|---|
| SRC-001 | NODE-001 —  | DEC-001 / нет |  | `nodes/...md` |

Каждая область или соседний узел, названные в подробных файлах, обязаны попасть
в реестр, даже если остаются непроработанными.
