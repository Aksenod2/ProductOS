# Agent Team Template — коробка для переноса синтетической команды

Переносимое ядро команды AI-агентов, обкатанное на реальном проекте OCS
(Owner Club System, май–июнь 2026): 602 коммита за 37 дней, ~120 экранов,
живой прод. Оркестратор — Claude (основная сессия), роли — субагенты Claude Code.

Это не «набор промптов», а система: роли + дисциплина + автоматические
предохранители + экзамены, рождённые из реальных провалов первого проекта.

## Из чего состоит

| Папка / файл | Что это |
|---|---|
| `core/ORCHESTRATOR.md` | Должностная оркестратора (проджект-менеджера) — копируется в новый проект как есть |
| `core/engineering-discipline.md` | Канон инженерной дисциплины — копируется в новый проект как есть |
| `core/CLAUDE-template.md` | Шаблон CLAUDE.md нового проекта (плейсхолдеры `{{...}}`) |
| `core/design-system-reconstruction.md` | Практика: реконструкция дизайн-системы из скринов-референсов (5 шагов, 2 гейта стейкхолдера) |
| `core/layout-spacing.md` | Канон: отступы между элементами — только на уровне лейаута (gap/Stack/Grid); margin у компонентов запрещён; исключения E1–E4; чек для ревью |
| `core/source-required.md` | Канон: источник обязателен — не выдумывать функционал/экраны/логику без БРД или макета; алгоритм «СТОП и пометить»; граница реконструкция vs домысел |
| `agents/` | 17 каркасов ролей: переносимая часть + блок `<project-specifics>` под проект |
| `hooks/` | Автоматические предохранители (гейт сборки перед пушем и др.) |
| `stakeholder/` | Журнал работ простым языком + уровни доверия стейкхолдера |
| `evals/EXAMS.md` | 24 экзамена команды — собраны из реальных фейлов OCS |
| `HISTORY.md` | Летопись первой команды: как мы работали, ошибались и взрослели |
| `INSTALL.md` | Пошаговый чек-лист разворачивания на новом проекте |

## Как развернуть на новом проекте (коротко)

1. **Скопировать ядро**: `core/engineering-discipline.md` → `.claude/team/`,
   нужные роли из `agents/` → `.claude/agents/`, хуки из `hooks/` → `.claude/hooks/`.
2. **Адаптировать под проект**: заполнить `<project-specifics>` в каждой роли,
   подставить команду сборки в хуки, создать CLAUDE.md из `core/CLAUDE-template.md`.
3. **Включить дисциплину с первого дня**: уровень доверия СТРОГИЙ, журнал работ,
   `docs/DEBTS.md`, прогнать экзамены из `evals/EXAMS.md`.

Подробный чек-лист с конкретикой «что заменить» — в [INSTALL.md](INSTALL.md).
