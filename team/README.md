# Agent Team Template — коробка для переноса синтетической команды

Переносимое ядро команды AI-агентов, обкатанное на реальном проекте OCS
(Owner Club System, май–июнь 2026): 602 коммита за 37 дней, ~120 экранов,
живой прод. Оркестратор — Codex (основная сессия), роли — субагенты.

Это не «набор промптов», а система: роли + дисциплина + автоматические
предохранители + экзамены, рождённые из реальных провалов первого проекта.

## Как подключить к новому проекту (коротко)

1. **Не копировать роли и ядро.** `ProductOS/team/` остаётся единственным мастером.
2. **Развернуть стандартный проектный контур** по `core/PROJECT-WORKSPACE.md`: `PROJECT.md`, `docs/epics/`, журналы, проверки и места для внешних вердиктов.
3. **Добавить проектный контекст** в `AGENTS.md`: домен, стек,
   команды, пути, ограничения и прод-гейты.
4. **Подключить тонкий адаптер** среды: он только направляет роль прочитать
   `core/ORCHESTRATOR.md`, `agents/<role>.md` и проектный контекст.
5. **Включить дисциплину с первого дня**: уровень доверия СТРОГИЙ, журнал работ,
   `docs/DEBTS.md`, прогнать экзамены из `evals/EXAMS.md`.

Подробный чек-лист с конкретикой «что заменить» — в [INSTALL.md](INSTALL.md).

Пользовательский сценарий с командами для Codex — в [корневом README](../README.md#быстрый-старт).
Быстрая машинная проверка коробки: `bash scripts/test-team.sh` из корня ProductOS.
