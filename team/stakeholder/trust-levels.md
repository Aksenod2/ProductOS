# Уровни доверия стейкхолдера — краткая выжимка

Полная версия — `core/engineering-discipline.md` §7. Здесь — то, что нужно
стейкхолдеру и оркестратору, чтобы выбрать уровень и осознанно его менять.

## Принцип

Чем меньше стейкхолдер видит область своими глазами, тем БОЛЬШЕ прозрачности
обязана давать команда из этой области. Интерфейс он проверит сам; бэкенд,
инфраструктуру и данные — нет. Невидимая область без принудительных отчётов =
чёрный ящик, где копятся тихие долги.

## Три уровня

### СТРОГИЙ — новая команда / новый проект (стартовый, всегда)
- Каждый блок работ из невидимой области → запись в журнал
  (`docs/journal/<область>.md`) простым языком.
- Каждая работа сдаётся с доказательством ПОВЕДЕНИЕМ («можно увидеть вот это»),
  не артефактами процесса («тесты зелёные», «миграция применена»).
- Все развилки — наверх, в продуктовом виде с последствиями вариантов.

### СТАНДАРТНЫЙ — после 1–2 чистых проектов
- Журнал ведётся по-прежнему.
- Стейкхолдера дёргают только по развилкам с продуктовыми последствиями;
  технические развилки команда решает сама и фиксирует почему.

### ЛЁГКИЙ — зрелая команда с накопленным доверием
- Журнал — по вехам (релизы, крупные блоки).
- Остальное — внутри команды; safety-гейты (security-review, прод-браузер)
  не ослабляются НИКОГДА, это не вопрос доверия.

## Чек-лист «когда можно ослаблять» (СТРОГИЙ → СТАНДАРТНЫЙ → ЛЁГКИЙ)

Ослабление допустимо, только если ВСЁ выполнено:
- [ ] Завершён минимум один проект (или крупная фаза) на текущем уровне
      без «сюрпризов из чёрного ящика» (долги/баги, о которых стейкхолдер
      узнал постфактум).
- [ ] Журнал вёлся реально, а не «для галочки»: записи понятны стейкхолдеру
      без переводчика (спросить его!).
- [ ] `docs/DEBTS.md` актуален: нет долгов, живущих только в головах/чатах.
- [ ] Автоматические предохранители (хуки) работают и проверены экзаменами.
- [ ] Стейкхолдер ЯВНО сказал «переходим на уровень X» — и это записано
      в CLAUDE.md проекта.

## Красные флаги деградации (не путать с доверием)

- «Давно не писали в журнал — наверное, можно не писать». Нет: это дрейф.
- Отчёты снова наполнились жаргоном.
- «Тесты зелёные» опять принимается как доказательство.
- Стейкхолдер начал спрашивать «а что там у нас с X?» — значит, прозрачность
  упала ниже его потребности; вернуться на уровень строже.

Любой красный флаг → откат на уровень строже без обсуждения, обсуждение потом.
