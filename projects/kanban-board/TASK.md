# TASK.md — Канбан-доска

**Проект:** Kanban Board (личная продуктивность)

## Проблема

Нет простой, быстрой доски для управления задачами — ни в Notion, ни в Asana, ни в Linear. Всё слишком тяжёлое для личного использования: 10 кликов чтобы перетащить карточку.

## Решение

Лёгкая канбан-доска с проектами, drag-and-drop, карточками с тегами/статусами/исполнителями. Всё в одном HTML-файле, работает оффлайн, данные в localStorage.

## Пользователь

Денис — один пользователь. Хочет быстро бросить задачу на доску, перетаскивать между колонками, менять статус. Без регистрации, без облака.

## Ключевые фичи (от заказчика)

1. **Drag-and-drop** — перетаскивание карточек между колонками (обязательно)
2. **Несколько проектов** — создавать и удалять проекты, переключаться между ними
3. **Карточки**: текст + описание + теги + статус + исполнитель (без подзадач)
4. **Светлый дизайн**

## Критерии приёмки

1. Три колонки: «Надо сделать», «В работе», «Готово»
2. Drag-and-drop карточек между колонками (нативный HTML5)
3. Создание/удаление проектов
4. Переключение между проектами
5. Создание новой карточки (клик по кнопке «+» в колонке)
6. Редактирование: название, описание, теги, статус, исполнитель
7. Удаление карточки
8. Данные сохраняются в localStorage (персистентность между проектами)
9. Работает оффлайн (один HTML-файл, без зависимостей)
10. Светлый дизайн, адаптивный (мобильные + десктоп)
11. Цветовое кодирование колонок
12. Счётчик задач в каждой колонке
