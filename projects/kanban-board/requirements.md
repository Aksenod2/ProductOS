# Requirements: Kanban Board

## Цель

Лёгкая канбан-доска для личной продуктивности — один HTML-файл, работает оффлайн, данные в localStorage. Минимум кликов: задача бросается на доску и перетаскивается между колонками мгновенно.

## Пользователь

Один пользователь — Денис. Не нужен аккаунт, регистрация, облако. Хочет быстро добавлять задачи, менять их статус перетаскиванием, управлять несколькими проектами.

## Функциональные требования

1. Три колонки: «Надо сделать», «В работе», «Готово» с цветовым кодированием.
2. Drag-and-drop карточек между колонками через нативный HTML5 Drag-and-Drop API.
3. Счётчик задач в заголовке каждой колонки.
4. Создание, удаление и переключение между проектами.
5. Создание новой карточки кнопкой «+» в любой колонке.
6. Редактирование карточки: название, описание, теги, статус, исполнитель.
7. Удаление карточки.
8. Персистентность данных через localStorage (между сессиями и между проектами).
9. Полная автономность — один HTML-файл, без сервера и зависимостей.
10. Адаптивный интерфейс для мобильных устройств и десктопа.

## Нефункциональные требования

1. Один HTML-файл, без сборщиков, без фреймворков, без внешних зависимостей.
2. Чистый JavaScript (ES6+) и CSS (без preprocessors).
3. Время отклика при drag-and-drop — мгновенно, без задержек.
4. localStorage — единственный источник данных; структура данных — JSON.
5. Код читаемый, структурированный, с комментариями в сложных местах.
6. Поддержка современных браузеров: Chrome, Safari, Firefox (последние 2 версии).
7. Светлая цветовая схема, контрастность текста не ниже 4.5:1.

## Пользовательские сценарии (User Stories с AC)

### US1. Добавить задачу на доску
**Как** пользователь, **я хочу** быстро создать карточку, **чтобы** не забыть о задаче.

**Acceptance Criteria:**
- AC1: Карточки создаются кнопкой «+» в нужной колонке.
- AC2: Открывается форма с полями: название (обязательное), описание, теги, исполнитель.
- AC3: Карточка появляется в колонке сразу после сохранения.
- AC4: Счётчик колонки обновляется.

### US2. Переместить задачу между колонками
**Как** пользователь, **я хочу** перетащить карточку в другую колонку, **чтобы** отразить прогресс.

**Acceptance Criteria:**
- AC1: Карточку можно перетаскивать (drag) за любую область.
- AC2: При наведении на колонку она подсвечивается.
- AC3: После drop карточка появляется в новой колонке, статус обновляется.
- AC4: Счётчики всех затронутых колонок обновляются.
- AC5: Перемещение сохраняется в localStorage.

### US3. Редактировать карточку
**Как** пользователь, **я хочу** открыть карточку и изменить её данные, **чтобы** актуализировать информацию.

**Acceptance Criteria:**
- AC1: Клик по карточке открывает модальное окно с формой редактирования.
- AC2: Поля формы: название, описание, теги (через запятую), статус (select), исполнитель.
- AC3: Кнопка «Сохранить» обновляет карточку и закрывает модалку.
- AC4: Кнопка «Отмена» закрывает модалку без изменений.
- AC5: Изменения сохраняются в localStorage.

### US4. Удалить карточку
**Как** пользователь, **я хочу** удалить ненужную карточку, **чтобы** доска оставалась чистой.

**Acceptance Criteria:**
- AC1: Кнопка удаления доступна в форме редактирования карточки.
- AC2: Подтверждение удаления (confirm dialog или кнопка «Удалить» с подтверждением).
- AC3: После удаления карточка исчезает, счётчик колонки уменьшается.
- AC4: Удаление сохраняется в localStorage.

### US5. Управлять проектами
**Как** пользователь, **я хочу** создавать, удалять и переключаться между проектами, **чтобы** разделять задачи по контекстам.

**Acceptance Criteria:**
- AC1: Панель проектов отображается в заголовке приложения.
- AC2: Кнопка «Создать проект» открывает поле ввода названия.
- AC3: Текущий проект выделен визуально.
- AC4: Кнопка удаления проекта рядом с названием (с подтверждением).
- AC5: Данные каждого проекта изолированы в localStorage по ключу `kanban:<projectId>`.
- AC6: Переключение между проектами мгновенное, без перезагрузки.

## Ограничения

1. Один пользователь — нет авторизации, ролей, совместной работы.
2. Один HTML-файл — нет CDN, нет npm-пакетов, нет бандлеров.
3. localStorage — нет серверного бэкапа, нет синхронизации между устройствами.
4. Нет подзадач, нет вложенности карточек.
5. Нет приоритетов, дедлайнов, фильтров и поиска.
6. Нет экспорта/импорта данных.
7. Нет тёмной темы.
