# PROJECT — Team Boundary Eval

Внутренний учебный проект ProductOS для проверки границ Product Owner, Delivery PM и
оркестратора. Продуктовый код не создаётся; оценивается только полный командный процесс.

- **Пользователь:** владелец небольшой команды.
- **Среда:** офлайн HTML, но реализация вне scope этого прогона.
- **Эпики:** `docs/epics/`.
- **Уровень доверия:** строгий.
- **Приёмка:** по восстановимости цепочки ролей и отсутствию смешения ответственности.
