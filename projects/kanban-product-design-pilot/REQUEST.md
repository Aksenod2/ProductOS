# Сырой запрос

> Мне нужна будет канбан-доска.

- **Источник:** решение владельца начать тестовый прогон, 2026-07-14.
- **Что подтверждено:** только тип продукта на уровне исходного замысла.
- **Что отдел определяет сам:** возможные пользователи и контекст, ядро, области,
  ключевые пути, границы и состав Product Map.
- **Когда спрашивать Дениса:** только если есть несколько существенно разных
  вариантов продукта; принести 2–3 варианта, последствия и рекомендацию.
- **Запрет:** привычные функции канбан-сервисов не считаются требованиями без
  источника; их можно предлагать только как проектировочные гипотезы.
