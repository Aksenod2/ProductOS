## 🚩 Проблемы — нужен глаз

### Блокировка cron (collect-facts.sh)
Скрипт `scripts/collect-facts.sh` лежит в проекте ProductOS, но Hermes Cron ищет его в `~/.hermes/profiles/app_factory/scripts/`. При попытке cron-запуска — security block: «script path resolves outside the scripts directory». При этом скрипт рабочий — прямой запуск через терминал даёт корректный JSON.

**Варианты решения:**
- **A**: скопировать/симлинковать `collect-facts.sh` в `~/.hermes/profiles/app_factory/scripts/`
- **B**: перенастроить cron-задачу указывать полный путь и разрешить cross-directory execution
- **C**: вызывать скрипт внутри cron-команды через `bash /full/path/to/collect-facts.sh` (не через Hermes script resolver)
