# ProductOS

Автономная система: DeepSeek Pro работает, дорогая модель надзирает.

## Структура

```
ProductOS/
├── constitution/
│   ├── SUPERVISOR-WORKER.md   ← контур: роли, факты, формат дайджеста
│   └── WORKER-PROMPT.md       ← промпт системы-воркера
├── team/                       ← коробка команды (из OCS, обкатана)
│   ├── agents/                 ← 13 ролей
│   ├── core/                   ← дисциплина + шаблон CLAUDE.md
│   ├── hooks/                  ← предохранители (build-gate и др.)
│   ├── stakeholder/            ← журнал + уровни доверия
│   └── evals/                  ← 24 экзамена + скоркарта
├── scripts/
│   └── collect-facts.sh        ← сбор объективных метрик
├── projects/                   ← активные проекты (пока пусто)
├── logs/
│   ├── digest-*.md             ← дайджесты (читают супервизоры)
│   └── raw/                    ← сырые логи + facts JSON
└── memory/                     ← память системы (пока пусто)
```

## Как это работает

1. **Воркер (каждые 4 часа)**: собирает факты → работает/сдаёт экзамен → пишет дайджест
2. **Супервизор (раз в день/неделю)**: читает `logs/digest-*.md` → сверяет факты vs самооценку → правит коробку

## Cron

- Или: DeepSeek Pro уже прогоняет экзамены автономно как самопроверка
