Узел 3 — Контроль / Ревью

Тип: Проверочный · Один артефакт + свод правил → Вердикт + замечания

Характеристики

  • • Тип: Проверочный
  • • Вход: артефакт + правила
  • • Выход: вердикт + замечания
  • • Не производит новый артефакт

Разбиение на агентов

  • • Микро-агент: базовые правила
  • • Микро-агент: целевые правила
  • • Сшивающий: вердикт + замечания
  • • Много правил → больше агентов

Где встречается

  • • Ревью дизайна
  • • Ревью кода
  • • Проверка договора
  • • Контроль отчёта
