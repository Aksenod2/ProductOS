Узел 2 — Синтез

Тип: Сходящийся · N ролевых входов → один артефакт-композит

Характеристики

  • • Тип: Сходящийся
  • • Вход: N ролевых источников
  • • Выход: артефакт-композит
  • • Требует уникальную роль каждого

Разбиение на агентов

  • • N источников → N микро-агентов
  • • Каждый = одно измерение
  • • +1 сшивающий агент
  • • Итого: N+1 микро-агент

Где встречается

  • • Структура сайта (3 анализа)
  • • Коммерческое предложение
  • • Договор (логистика)
  • • Где нужно собрать из ролей
